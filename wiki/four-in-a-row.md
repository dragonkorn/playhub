# Four in a Row

Two players take turns dropping discs into a 7 by 6 board, and four in a line wins. Thai name เรียงสี่. The app never says "Connect Four", because that name is a Hasbro trademark. Rules are in the [Four in a Row spec](../specs/games/four-in-a-row/spec.md).

## Flow

1. **Setup:** the server shuffles the two players. The first plays yellow and moves first (F3).
2. **Play:** the current player picks a column, and the disc lands on the lowest empty row (F5). Full and off-board columns are refused, and the turn stays (F6).
3. **Finish:** four in a line, across, up or diagonal, wins at once (F7). A full board with no line is a draw, ranked as a tie (F9). If a player leaves, the other wins (F11).

There is no hidden information, so every player and watcher gets the same view, and the test kit's secret list is empty.

## Data

The drop log is the only record of the board. `logic/board.ts` holds the board size, column heights and line finding, which the `ui` reuses to grey out full columns. `line` lists every cell of every winning run through the last disc, so a move that completes two lines lights up both (F8).

## Screen

One landscape screen on the shared `GameLayout`, so the game declares `orientations: ["landscape"]` ([Screens and frames](screens-and-frames.md)): players and disc colors on the left, the board in the middle, the latest moves and the Drop button on the right. A tap selects a column and shows a ghost disc above it, and Drop confirms (F13). Discs also differ by an inner ring or dot, for players who can't tell the colors apart (F16).

## Move feedback

Each new drop falls, lands with a sound, and on a win the line pulses under a banner (F18). Playback runs through the shared log playback in `packages/ui`, the same one Battleship uses ([Design system](design-system.md)), so drops stay hidden until they land and a reconnecting device skips what it missed (F19). The game sets `holdsFinish`, so the last drop plays before the result screen.

There are 6 sounds, generated by `design/assets/four-in-a-row/build-sounds.mjs`, then copied into `ui/assets/sounds` (F21). CSS class names start with `fir-`, because every game's CSS loads into one app. Reduce Motion turns the fall into a fade and stops the pulse (F22).

## Local play

The game opts in to [Local play](local-play.md). With the board's `local` prop set, texts name the player instead of saying "you", the turn banner names who is up next, and a win always plays the win sound (F23, F24).
